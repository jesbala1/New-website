JESBALA V7 — Interactive Halftone Sun

Open index.html in a browser. The homepage includes a dense green halftone sun. Hover to gently displace dots, click/tap or keyboard activate to cycle seven shapes. Motion is reduced when the operating system requests reduced motion.

To publish on GitHub: open your jesbala1/New-website repository, upload the UPDATED index.html, style.css and NEW sun.js to the repository root, then commit. All other files can stay as they are.

The other pages are unchanged from V6. No external dependencies.
