# JESBALA — minimal website template

Open `index.html` in Safari to preview. All pages are linked.

## Replace images
Put your artwork or photography in `assets/`, then edit the `src="assets/art-01.svg"` paths in the HTML files to your image filenames. Replace placeholder project titles and metadata.

## Publish for free
Upload the folder to Netlify or GitHub Pages. After publishing, configure jesbala.com in the host dashboard and update DNS at your domain registrar. Do not cancel your domain registration.

## Notes
This is an original, minimalist template drawing on general archival layout principles, not a copy of another artist's code, artwork, or branding. All placeholders are local, so the site previews offline.
